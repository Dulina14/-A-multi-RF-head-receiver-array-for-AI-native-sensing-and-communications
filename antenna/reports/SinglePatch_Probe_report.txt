Corporate divider impedance proof (1 -> 2 -> 4 -> 8 -> 16)
  Claim: every branch presents 50 ohm at its own input.
  Base case (stage 4): patch edge 153.00 ohm -> 87.46 ohm quarter wave gives 87.46^2/153.00 = 50.00 ohm;
    the 50 ohm run is then matched, so the stage-4 branch input (before its own 70.71 ohm section) is 50 ohm.
  Induction step: a branch whose subtree presents 50 ohm is raised by its 70.710 ohm quarter wave to 70.710^2/50 = 100.00 ohm;
    two identical branches in parallel at the tee give 50.00 ohm, and the parent 50 ohm line is matched.
  Therefore the SAME 70.71 ohm quarter wave is correct at every one of the four stages, provided it is placed on the
  CHILD side of each tee, immediately at the junction.  It is placed there in this script, so there is no stray 50 ohm
  stub between a tee and its transformer.  A 35.36 ohm section would only be correct for the opposite placement
  (transformer on the parent side, feeding two 50 ohm branches directly); that variant is not used here.
